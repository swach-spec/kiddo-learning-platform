# Illustration references

Character and avatar reference sheets used to keep every KIDDO picture consistent.
Attach the relevant character from these sheets when generating story scenes
(see the "KIDDO Illustration Prompt Pack" doc for prompts and file names).

- `character-sheet-v1.jpg` — Grade 2, 3 and 6 story characters and the 8 explorer avatars.
- `character-sheet-v1-detailed.jpg` — the same characters with their written descriptions.

The app's avatar files in `public/images/avatars/` were cropped from `character-sheet-v1.jpg`.
